# WMCS releases

WMCS пока не публиковал стабильный релиз. Публичный репозиторий начинается с
alpha-линии, а compatibility claims всегда привязаны к конкретному commit,
OpenWrt target, устройству и evidence.

| Release line | Stage | Scope |
|---|---|---|
| 0.1.x | Experimental alpha | Один controller, один agent, pairing, one-WLAN control и rollback |
| 0.2.x | Planned alpha | Signed release path, power-cut recovery и расширенная multi-node модель |
| 1.0.x | Future | Поддерживаемый native WMCS release после закрытия release gates |

Git tags остаются машинно-читаемыми семантическими версиями. Непомеченные
лабораторные сборки не являются release artifacts.
